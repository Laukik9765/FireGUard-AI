## 🗺️ Core Architecture Overview

- **Backend / Web Server**: Flask + Flask-SocketIO in [`app.py`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/app.py). Serves real-time MJPEG camera streams, WebSocket event streams (`/stream`), REST endpoints (`/api/*`), and the 3D interactive knowledge graph (`/graph`).
- **Detection Engine**: [`models/locate_anything/mock_detector.py`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/models/locate_anything/mock_detector.py) (precision 5-gate fire detector with HSV color gating, RGB slope, spatial variance, temporal flicker buffer, and minimum pixel mass; plus 4-gate smoke detector).
- **Hazard Scoring Engine**: [`models/hazard_level/hazard_engine.py`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/models/hazard_level/hazard_engine.py) computes temporal hazard metrics (0–100), exponential smoothing, spread rates, and danger levels (Low, Moderate, High, Severe, Extreme).
- **Frontend Dashboard**:
  - [`dashboard/templates/index.html`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/dashboard/templates/index.html) (Cyber-neon aesthetic, video feeds, 5-level colored hazard gauge, sidebar live alert cards).
  - [`dashboard/static/js/dashboard.js`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/dashboard/static/js/dashboard.js) (SocketIO listeners, live chart telemetry, alert updates in `#card-alert`, gauge level transitions).
  - [`dashboard/static/css/style.css`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/dashboard/static/css/style.css) (Glassmorphism, glow effects, vibrant neon badges).
- **Graphify 3D Visualizer**: Served at `/graph` via [`graphify-out/graph.html`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/graphify-out/graph.html), generated by [`generate_3d_graph.py`](file:///c:/Users/lauki/OneDrive/Desktop/fireguard%20AI/generate_3d_graph.py).
